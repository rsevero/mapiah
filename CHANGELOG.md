# Changelog

## 0.4.5 - not yet released
* New features:
  * Added a `B` keyboard shortcut to toggle the `border` option on selected slope lines, matching the existing `R`/`S` shortcuts for reverse/smooth. Works both when editing a single line and when a non-empty multi-selection is active; non-slope lines in the selection are left untouched.
  * Added a `V` keyboard shortcut to toggle the `visibility` option on selected lines, points, and areas, following the same pattern as the `B`/`R`/`S` toggles. Also renamed the "flip" image/element transform actions to "mirror" throughout the UI, help text, and code, and moved their shortcuts to `Alt+M` (horizontal) and `Ctrl+M` (vertical) to free up `H`/`V` for this toggle and for a future one; "Merge areas" moved to `Ctrl+Alt+M` to avoid clashing with the new vertical-mirror shortcut.
  * Added the Therion project tree side column in the file editor: a collapsible, resizable panel showing the loaded `thconfig`/`.th`/`.th2`/logical-node hierarchy, with expand/collapse, search filtering, dirty and error status dots, a draggable divider, persisted sidebar width/collapsed state, and an empty-state Open Project action wired to `THProjectController.openProject`. Added `THProjectTreeUIController` for view-only expansion/filter/sidebar state and widget/unit coverage (`test/t3880`–`t3884`).
  * Project-tree default expansion now walks down branch-by-branch until it reaches the shallowest `.th2` file, then opens every branch to that same depth. Projects without a `.th2` file are fully expanded.
  * Clicking a `.th2` file in the project tree now opens or focuses its canvas tab.
  * `thconfig`/`.th` files now open as tabs in the file editor alongside `.th2` canvas tabs. Clicking a `thconfig`/`.th` project-tree node opens or focuses its text-editor tab; clicking a survey/centreline/map/inline-scrap node opens or focuses its containing file's tab and scrolls to that block's line. Switching tabs (by any means) now also updates which project-tree node is selected/expanded, and unsaved canvas edits now light up the same tree dirty dot that text-editor edits already did. Ctrl/Cmd+S saves whichever tab type is active; the Properties tab button is hidden for text-editor tabs, which have no equivalent page.
  * Added a way to close the currently loaded Therion project: a Close button in the project-tree sidebar header, and a matching "Close project" entry in both the initial window's and the file editor's compact overflow menus. Closing a project also closes any open canvas/text-editor tabs belonging to it (leaving unrelated standalone tabs open), since a `thconfig`/`.th` tab left open after closing would otherwise silently fail to save once its project node lookup no longer resolves.
  * Replaced the separate initial window with the always-mounted tabbed workspace, keeping the project tree available even when no file tabs are open and eliminating editor-route overlap when tabs close and reopen. Startup file handling, telemetry consent, update checks, and About now live on the root tabs page. The empty project tree exposes Open project, Open project and run Therion, and a localized New project placeholder; Ctrl/Cmd+O now opens a project, while obsolete standalone TH2 open/new-file toolbar actions and their Ctrl/Cmd+N and Ctrl/Cmd+T shortcuts were removed. Updated responsive, dialog, tab-lifecycle, and Therion-action widget coverage for the unified layout.
  * Implemented Phase 10 of the Therion project parsing roadmap: Save As for `thconfig`/`.th` text-editor tabs, the app-bar button, compact overflow entry, and Ctrl/Cmd+Shift+S now route to it (previously TH2-only). Unlike TH2 Save As (which only rebases image references inside the moved file), text Save As is project-graph aware: `THProjectController.saveTextProjectFileAs(...)` rewrites both the moved file's own relative `source`/`input`/`import` directives and every other loaded file's incoming reference to it (including references nested inside `survey` blocks), via a new pure `THDirectiveRewriteAux` helper, then rebuilds the project in memory (root or non-root) reusing Phase 8.5's revision/override machinery — the old file is retained on disk untouched, and rewritten referencing files become ordinary dirty tabs saved only through the normal Save/Save All path. A `thconfig` file keeps any chosen filename verbatim; a `.th` file gets `.th` appended when the chosen name has no extension. Destination collisions (against another project node or an already-open tab) are rejected before any write; a failed rebuild leaves the pre-Save-As project/editor identity fully intact, with the written destination file as a documented, accepted residue. `MPGeneralController.renameFileController(...)` now also migrates the `THTextEditorController` registry entry (previously TH2-only). Multi-line `source ... endsource` blocks are a documented, deliberate non-goal. Added EN/PT localization and keyboard-shortcut help updates, and test coverage (`test/t3933`–`t3937`).
  * Project-tree element rows now show a station's `-name`, and the `-text` of label and remark points, in italics between the type and the Therion id (#32, Phase 5). Multi-line texts show all their lines in a tooltip on hover. Search matches these values, and rows update when they are edited, undone or redone. Added tests (`test/t3951`) and updated two Phase 3 tests (`test/t3942`, `test/t3944`) that expected station names to stay out of labels and not to refresh the tree.
  * Project-tree drawing order is editable (#32, Phase 4): drag scraps or drawing elements between positions, use their right-click order menu or Move to scrap submenu, and reorder the canvas selection with Ctrl/Cmd+[ or Ctrl/Cmd+] (Shift moves to either end). Ctrl/Shift clicks select multiple tree rows; scraps have a separate tree selection. Edits are validated and undoable, with EN/PT feedback and help. Added move-resolution, drag, menu and shortcut tests (`test/t3947`–`t3950`) and updated tree tests (`test/t3943`).
  * The project tree now shows the contents of `.th2` files in file (drawing) order (#32, Phase 3 of the TH2 element tree plan, read-only):
    * Expanding a `.th2` file row lists its scraps and, below each scrap, its points, lines and areas, each with its kind, type[:subtype] and Therion id. The top row is drawn first and the last row on top; the header tooltip explains this.
    * The file is loaded in the background when its row is expanded, without opening a tab or changing anything. Rows update after loads, undo/redo and type, subtype or id changes. Scraps can be collapsed.
    * Clicking an element selects it in its file (bringing an open tab to the front, or without opening a tab); double-clicking also opens the tab if needed and zooms to the selection. Selections made on the canvas are highlighted in the tree, and a collapsed scrap shows a dot when it contains the selection.
    * The tree search also matches the elements of loaded, valid files.
    * Broken files show a problem-count badge and a status row; broken files and files whose load failed offer Reload in a right-click menu. Reload now also updates an open tab in place, and never reopens or activates a tab.
    * Closing the tab of a file whose tree row is expanded keeps its loaded state for the tree when it has no unsaved changes.
    * Default project-tree expansion now opens every non-`.th2` node down to the shallowest `.th2` depth and never expands a `.th2` row.
    * Added EN/PT strings and editor help, and tests `test/t3942`–`t3944` (plus updates to `test/t3880`, `t3881` and `t3883`).
* Fixed bugs:
  * On Windows, Save As of an existing `.th2` file no longer breaks or lowercases its image paths.
    * Relative image paths could be rewritten into broken paths such as `../../../../c:/caves/…`, so the images stopped loading. They now point to the same file, with the original letter case.
    * Absolute image paths were rewritten in lowercase. They are now left exactly as written, and their lines keep their original formatting.
    * An image on a different drive from the new file keeps its absolute path.

    The cause was `p.canonicalize`, which lowercases paths on Windows, combined with a case-sensitive POSIX relative-path calculation. Added Windows-path tests (`test/t0816`).
  * On Windows, a Therion run that ends in a fatal error no longer leaves the run dialog stuck in the yellow running state with the elapsed timer counting forever. Therion's Windows build pauses on fatal errors with "Press ENTER to exit!" and waits for keyboard input, and so do MetaPost and pdfTeX when they hit an error; Mapiah kept their input open, so they waited forever. Mapiah now closes Therion's input as soon as it starts, so these pauses end at once and the dialog shows the red error status. Added regression coverage (`test/t3600`). [reported by CaverBruce]
  * Right-dragging (panning) the `.th2` drawing area no longer draws its elements over the project sidebar to its left; the canvas is now clipped to its own bounds on every side.
  * Clicking anywhere outside the `.th2` drawing area (app bar buttons or empty space, tab strip, project tree, bottom status bar, last-used PLA buttons) now closes every secondary window opened over the drawing area (options, default options, scrap options, PLA types, etc.). Previously only clicks on the canvas itself dismissed them, so they stayed open, e.g., over the Settings page. Clicks on the windows themselves, or on dialogs/menus opened from them, keep them open. Added widget coverage (`test/t3938`).
  * `.th2` files are no longer parsed with stray NUL (`\0`) characters embedded in string values (seen in files corrupted by other tools mis-handling UTF-16 content). A NUL byte in a `text`/`mark`/`title`/attribute value confused the text field's native focus handling, making the existing value appear to vanish as soon as the field was edited; NUL characters are now discarded right after decoding a file, before parsing begins.
  * The options edit dialog's `text`/`mark`/`title` field no longer selects its entire existing value when it gains focus on Linux/macOS/Windows, which fought against editing (appending to) existing text; and canvas keyboard shortcuts (`O`, `B`, `V`, etc.) no longer fire while a text field elsewhere has keyboard focus.
  * The bottom status bar message and the options edit panel for a selected element now update immediately whenever one of its options is set or unset, regardless of how the change was made (keyboard shortcut toggles for border/visibility/reverse/smooth, or the options edit dialog itself). Previously the displayed text/state could go stale until an unrelated action (reselecting, moving the element) forced a refresh.
  * Typing `T` in a `thconfig`/`.th` text editor tab no longer runs Therion instead of inserting the letter. The plain-`T` rerun shortcut is now suppressed whenever a text field has keyboard focus, instead of being registered as an unconditional global shortcut that always swallowed the keystroke.
  * Restored Ctrl/Cmd+T in the unified main workspace to choose a project and run Therion, limited to the empty-project state. Once a project is loaded, Ctrl/Cmd+T is unavailable and plain `T` reruns Therion against that project's root config; the run dialog likewise no longer offers a choose-another-project shortcut. The empty workspace takes initial keyboard focus so Ctrl/Cmd+T works before any file tab is open. Added behavioral regression coverage for both modifiers, loaded-project suppression, the run dialog, and project-tree search focus.
  * The release-summary generator now writes both the canonical `releases/releases_summary.json` file and an independent `assets/releases/releases_summary.json` copy for compatibility with older app builds.
  * The options dialog's `Subtipo`/subtype dropdown now sorts its entries alphabetically by their translated label instead of by raw (English) internal key, fixing non-alphabetical ordering in Portuguese and other locales.
  * Restored initial keyboard focus to an editor tab that was already active when the unified workspace mounted, so its editing shortcuts work without first clicking or reselecting the tab. Updated the shared workspace test harness to keep the unrelated first-launch telemetry prompt from absorbing editor interactions.
  * Rerunning Therion from its run dialog now clears the loaded project's stale compiler diagnostics as soon as the new run starts, matching the initial-run behavior instead of leaving old tree and editor markers visible until the rerun finishes.
  * Added deterministic action-routing coverage for Run Therion: the loaded project path is now verified through an injected run starter, while the expanded toolbar button, compact overflow-menu item, and empty-project tree action are tapped through injected page/tree callbacks without spawning a real Therion process.
  * On Windows (and other desktop platforms), closing Mapiah via the window's close button, taskbar control, or Alt+F4/Ctrl+F4 no longer leaves the window visibly frozen on screen for several seconds before it vanishes; the window is now hidden right after its placement is persisted, so the Flutter engine's shutdown happens invisibly in the background afterward instead of behind a still-visible, unresponsive window. [reported by CaverBruce]
  * The project-tree Open project action now always treats the selected file as a `thconfig` root, including files with arbitrary extensions or no extension. Project shape detection also now recognizes `.thconfig`-suffixed filenames, so showcase configs such as `therion_uis_showcase.thconfig` load their `source`/`input` tree instead of being misdetected as `.th` data files. Added parser and controller regression coverage.
  * Broken `.th2` files (#32, Phase 1) are now reported more precisely:
    * A structural error no longer produces extra errors further down the file. A `point`, `line` or `area` outside any scrap, a scrap inside another scrap, and a missing `endline`/`endarea` are each reported once, at the right line. An unclosed scrap, line or area at the end of the file no longer adds a generic "multiline commands left open" error.
    * An unknown option on a `scrap`, `line` or `area` line is reported once at that line, and the rest of the block is read normally instead of being skipped. A misspelled command inside a scrap no longer hides the lines after it.
    * An unknown option line inside an area (for example `weirdareaopt 5` or `clip middle`) is reported instead of being dropped silently.
    * A malformed `##XTHERION## xth_me_image_insert` line is reported instead of making the load fail.
    * Problems are listed in line order.
  * Areas whose border lines use unusual ids are no longer deleted silently when a `.th2` file is opened, and valid ids are no longer changed (#32):
    * `-id` values now follow Therion's ext_keyword rule. Valid ids such as `p.1`, `a+b` or `o'neil` are kept as written; before, every character other than letters, digits, `/` and `-` became `_` (so `p.1` was saved as `p_1`).
    * A border reference written as `line@survey` now finds the line `line`, as in Therion, and is saved as written.
    * When Mapiah has to repair an invalid line id (for example `-id b@1` becomes `b_1`), border references that spell the same id are repaired the same way. Before, the two sides were repaired differently, the reference no longer matched, and the area was removed.
    * Added parser tests (`test/t3946`).
  * An area border reference that names no line of the `.th2` file, or names something that is not a line (for example a point), now marks the file as broken with an "invalid border reference" problem at that line. Before, the reference was dropped silently when the file was opened, and the area too when it had no border left, so saving lost them. The affected `test/t0600` cases now expect a broken file, and `test/t3158` uses a new valid fixture.
  * Save As is disabled for broken `.th2` files in the toolbar and the overflow menu, as the broken-file panel already promised.
  * Reloading a broken `.th2` file from its tab after fixing it on disk now shows the canvas. Before, the tab kept using the discarded controller and still showed the broken-file panel.
  * Fixed several problems in the element move commands added for #32 (Phase 2), which no user action reaches yet:
    * A move that only steps over a comment or another hidden line is now a no-op.
    * Moving an area to another scrap together with its selected border line, or two areas that share a border line, no longer moves that line several times.
    * "Bring forward" now works on the next-to-last element, "Bring to front" and "Send to back" were swapped, and they report a no-op at the first or last position instead of a rejection.
    * A selected element that leaves the active scrap is deselected, the selection of a moved element stays current, and station names are updated when a station moves to another scrap.
