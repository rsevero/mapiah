## 0.4.5 - not yet released
* New features:
  * Added the Therion project tree side column in the file editor: a collapsible, resizable panel showing the loaded `thconfig`/`.th`/`.th2`/logical-node hierarchy, with expand/collapse, search filtering, dirty and error status dots, a draggable divider, persisted sidebar width/collapsed state, and an empty-state Open Project action wired to `THProjectController.openProject`. Added `THProjectTreeUIController` for view-only expansion/filter/sidebar state and widget/unit coverage (`test/t3880`–`t3884`).
  * Project-tree default expansion now walks down branch-by-branch until it reaches the shallowest `.th2` file, then opens every branch to that same depth. Projects without a `.th2` file are fully expanded.
  * Clicking a `.th2` file in the project tree now opens or focuses its canvas tab.
  * `thconfig`/`.th` files now open as tabs in the file editor alongside `.th2` canvas tabs. Clicking a `thconfig`/`.th` project-tree node opens or focuses its text-editor tab; clicking a survey/centreline/map/inline-scrap node opens or focuses its containing file's tab and scrolls to that block's line. Switching tabs (by any means) now also updates which project-tree node is selected/expanded, and unsaved canvas edits now light up the same tree dirty dot that text-editor edits already did. Ctrl/Cmd+S saves whichever tab type is active; the Properties tab button is hidden for text-editor tabs, which have no equivalent page.
  * Added a way to close the currently loaded Therion project: a Close button in the project-tree sidebar header, and a matching "Close project" entry in both the initial window's and the file editor's compact overflow menus. Closing a project also closes any open canvas/text-editor tabs belonging to it (leaving unrelated standalone tabs open), since a `thconfig`/`.th` tab left open after closing would otherwise silently fail to save once its project node lookup no longer resolves.
  * Replaced the separate initial window with the always-mounted tabbed workspace, keeping the project tree available even when no file tabs are open and eliminating editor-route overlap when tabs close and reopen. Startup file handling, telemetry consent, update checks, and About now live on the root tabs page. The empty project tree exposes Open project, Open project and run Therion, and a localized New project placeholder; Ctrl/Cmd+O now opens a project, while obsolete standalone TH2 open/new-file toolbar actions and their Ctrl/Cmd+N and Ctrl/Cmd+T shortcuts were removed. Updated responsive, dialog, tab-lifecycle, and Therion-action widget coverage for the unified layout.

## 0.4.4 - 2026-08-23 - The Cave Rescue release
* Highlights:
  * Continued closing the Therion UIS fidelity gap from 0.4.3:
    * Implemented point symbols for types that previously had no Therion UIS representation at all and fell back to Mapiah's placeholder: `helictites`, `stalactite-stalagmite`/`stalactites-stalagmites`, `pillar-with-curtains`/`pillars-with-curtains`, `disc-pillar`/`disc-pillars`, `disc-stalactite`/`disc-stalactites`, `disc-stalagmite`, `debris`, and `curtains`.
    * Corrected existing symbols to match Therion's own macros more closely: `moonmilk`'s taller middle bump, `paleo-material`'s bone silhouette, `guano`'s V profile, `sand`'s dot triangle, `disc-stalagmites`' vertical stagger, `air-draught`'s wing curve, and `flute`'s under-belly depth; fixed missing/hollow arrowheads on all three `water-flow` subtypes and restored visible dashes on `-subtype intermittent`; and stopped `pillar`, `continuation`, `pillars`, `stalactites`, `stalagmites`, and other stroke-only symbols from painting stray filled triangles during the fill pass.
  * Overhauled Therion-faithful `passage-height` point containers and related text points: unfilled, smaller-font outlines matching Therion's `\thframed` styling, then re-filled with the same white background as `label`/`remark`/`date`/`altitude`/`height`/`dimensions` for legibility; dropped the spurious unit suffix from `height`/`passage-height` labels; and unified all faithful text points on the same reduced text size.
  * Fixed Mapiah not closing on Windows (and other desktop platforms) via the window's close button, taskbar control, or Alt+F4/Ctrl+F4. [reported by CaverBruce]
  * Decoupled Therion UIS point, line, and area paints from Mapiah's unrelated placeholder renderer, and upgraded to Flutter 3.47.0 (migrating from `package:flutter/material.dart` to `package:material_ui/material_ui.dart` and fixing the `file_picker` 12.0.0 API rewrite).
* New features:
* Fixed bugs:
  * On Windows (and other desktop platforms), closing Mapiah via the window's close button, taskbar control, or Alt+F4/Ctrl+F4 no longer silently does nothing; the desktop close handler now force-closes the native window with `windowManager.destroy()` after persisting window placement, instead of the mobile-oriented `SystemNavigator.pop()`, which doesn't reliably terminate a desktop window once native close interception is enabled. [reported by CaverBruce]
  * Therion UIS `pitch` lines now render with the same continuous `PenC` base line and `PenD` perpendicular ticks as `pit`, instead of falling back to Mapiah's dashed placeholder; Therion accepts `pitch` as an input alias of `pit`, so both are now routed to the shared pit/floor-step line decorator. Added dispatch regression coverage.
  * Therion UIS `rock-edge` lines now render as a continuous, very thin `PenD` stroke matching `l_rockedge_UIS`, instead of Mapiah's dashed medium-width placeholder. Added a dedicated line decorator and dispatch regression coverage.
  * Therion UIS `wall:presumed` lines now render with a plain, evenly-spaced dash pattern twice as long as `wall:underlying`'s, matching `l_wall_presumed_UIS` (`dashed evenly scaled (2*optical_zoom)`), instead of Mapiah's dash-dot pattern, which added small dots not present in Therion's macro.
  * Therion UIS `passage-height` point containers (the up/down/up-and-down/unsigned boxes around a passage height value) now render as thin unfilled outlines with a smaller font, matching Therion's `process_uplabel`/`process_downlabel`/`process_updownlabel`/`process_circledlabel` (all stroked with `PenD`, never filled, and set with `\thframed`'s reduced size) instead of Mapiah's solid white-filled, normal-sized shapes: an unsigned single number gets a circle, a signed single number (up-only or down-only) gets a short half-capsule rounded on its sign's side, and two numbers (up-and-down) share a full capsule split by a divider.
  * The orange circle marking a Therion-faithful text point's exact anchor position no longer paints on top of the point's own label, obscuring it; it's now drawn behind the label's text/container, but above its filled background box.
  * Therion UIS `passage-height` point containers (circle, half-capsule, and capsule) are now filled with the same white background as `label`/`remark`/`date`/`altitude`/`height`/`dimensions` points, instead of staying unfilled, for readability over busy scrap content and visual consistency with the other text-mode point types; like that background itself, this fill has no equivalent in Therion's own (frameless/unfilled) rendering of these containers.
  * Therion UIS `height` and `passage-height` point labels no longer append the unit (e.g. `40? ft` → `40?`); Therion's `format_human_length` formats these values without a unit suffix regardless of the point's `-unit` option, so Mapiah's appended unit had no equivalent in Therion's own output.
  * Therion UIS `label`, `remark`, `date`, `altitude`, `height`, and `dimensions` point text now renders at the same reduced size as `passage-height`'s containers (`THLabelSize.tiny`), instead of Mapiah's normal-sized text, which looked oversized compared to Therion's own rendering.
  * Therion UIS `water-flow -subtype paleo` points now render with a solid, filled arrowhead, matching `p_waterflow_paleo_UIS` (which both `thfill`s and `thdraw`s its triangle), instead of Mapiah's hollow outline-only arrowhead.
  * Therion UIS `moonmilk` points now render with three wavy tops, the middle one taller than the two side ones, matching `p_moonmilk_UIS`'s direction-constrained curve; the middle bump previously dipped instead of rising, and once fixed to rise, was the same height as the side bumps instead of taller.
  * Therion UIS `paleo-material` points now render as a bone silhouette — a shaft with two same-sized pairs of round knuckles at each end — instead of the previous blob shape, which didn't read as a bone at all; `p_paleomaterial_UIS`'s raw node sequence pinches to a sharp point when hand-ported as a single Bezier chain, so the knuckles are built from overlapping circles instead.
  * Therion UIS `pillar`, `continuation`, `pillars`, `stalactites`, and `stalagmites` points (plus, defensively, `stalactite`, `stalagmite`, `wall-calcite`, `karren`, `flute`, and `soda-straw`) no longer paint stray filled triangles/slivers at their line corners; their macros only `thdraw`, never `thfill`, but the shared fill/stroke draw dispatch also calls each symbol's draw method with a fill-style `Paint`, and Skia implicitly closes open subpaths when filling, turning V-shaped and zigzag strokes into unwanted solid wedges. Each now skips its own draw method on the fill pass. Added dispatch and golden regression coverage.
  * Therion UIS `water-flow -subtype permanent` and `-subtype intermittent` points now render with a solid, filled arrowhead, matching `p_waterflow_permanent_UIS`/`p_waterflow_intermittent_UIS` (fixed alongside `-subtype paleo` in the previous entry, but until now missed for these two subtypes since they never received a fill color at all).
