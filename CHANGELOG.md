## 0.4.4 - 2026-08-23 - The Cave Rescue release
* Highlights:
  * Continued closing the Therion UIS fidelity gap from 0.4.3:
    * Implemented point symbols for types that previously had no Therion UIS representation at all and fell back to Mapiah's placeholder: `helictites`, `stalactite-stalagmite`/`stalactites-stalagmites`, `pillar-with-curtains`/`pillars-with-curtains`, `disc-pillar`/`disc-pillars`, `disc-stalactite`/`disc-stalactites`, `disc-stalagmite`, `debris`, and `curtains`.
    * Corrected existing symbols to match Therion's own macros more closely: `moonmilk`'s taller middle bump, `paleo-material`'s bone silhouette, `guano`'s V profile, `sand`'s dot triangle, `disc-stalagmites`' vertical stagger, `air-draught`'s wing curve, and `flute`'s under-belly depth; fixed missing/hollow arrowheads on all three `water-flow` subtypes and restored visible dashes on `-subtype intermittent`; and stopped `pillar`, `continuation`, `pillars`, `stalactites`, `stalagmites`, and other stroke-only symbols from painting stray filled triangles during the fill pass.
  * Overhauled Therion-faithful `passage-height` point containers and related text points: unfilled, smaller-font outlines matching Therion's `\thframed` styling, then re-filled with the same white background as `label`/`remark`/`date`/`altitude`/`height`/`dimensions` for legibility; dropped the spurious unit suffix from `height`/`passage-height` labels; and unified all faithful text points on the same reduced text size.
  * Fixed Mapiah not closing on Windows (and other desktop platforms) via the window's close button, taskbar control, or Alt+F4/Ctrl+F4. [reported by CaverBruce]
  * Decoupled Therion UIS point, line, and area paints from Mapiah's unrelated placeholder renderer, and upgraded to Flutter 3.47.0 (migrating from `package:flutter/material.dart` to `package:material_ui/material_ui.dart` and fixing the `file_picker` 12.0.0 API rewrite).
* New features:
* Fixed bugs:
  * On Windows (and other desktop platforms), closing Mapiah via the window's close button, taskbar control, or Alt+F4/Ctrl+F4 no longer silently does nothing; the desktop close handler now force-closes the native window with `windowManager.destroy()` after persisting window placement, instead of the mobile-oriented `SystemNavigator.pop()`, which doesn't reliably terminate a desktop window once native close interception is enabled. [reported by CaverBruce]
  * Therion UIS `pitch` lines now render with the same continuous `PenC` base line and `PenD` perpendicular ticks as `pit`, instead of falling back to Mapiah's dashed placeholder; Therion accepts `pitch` as an input alias of `pit`, so both are now routed to the shared pit/floor-step line decorator. Added dispatch regression coverage.
  * Therion UIS `rock-edge` lines now render as a continuous, very thin `PenD` stroke matching `l_rockedge_UIS`, instead of Mapiah's dashed medium-width placeholder. Added a dedicated line decorator and dispatch regression coverage.
  * Therion UIS `wall:presumed` lines now render with a plain, evenly-spaced dash pattern twice as long as `wall:underlying`'s, matching `l_wall_presumed_UIS` (`dashed evenly scaled (2*optical_zoom)`), instead of Mapiah's dash-dot pattern, which added small dots not present in Therion's macro.
  * Therion UIS `passage-height` point containers (the up/down/up-and-down/unsigned boxes around a passage height value) now render as thin unfilled outlines with a smaller font, matching Therion's `process_uplabel`/`process_downlabel`/`process_updownlabel`/`process_circledlabel` (all stroked with `PenD`, never filled, and set with `\thframed`'s reduced size) instead of Mapiah's solid white-filled, normal-sized shapes: an unsigned single number gets a circle, a signed single number (up-only or down-only) gets a short half-capsule rounded on its sign's side, and two numbers (up-and-down) share a full capsule split by a divider.
  * The orange circle marking a Therion-faithful text point's exact anchor position no longer paints on top of the point's own label, obscuring it; it's now drawn behind the label's text/container, but above its filled background box.
  * Therion UIS `passage-height` point containers (circle, half-capsule, and capsule) are now filled with the same white background as `label`/`remark`/`date`/`altitude`/`height`/`dimensions` points, instead of staying unfilled, for readability over busy scrap content and visual consistency with the other text-mode point types; like that background itself, this fill has no equivalent in Therion's own (frameless/unfilled) rendering of these containers.
  * Therion UIS `height` and `passage-height` point labels no longer append the unit (e.g. `40? ft` → `40?`); Therion's `format_human_length` formats these values without a unit suffix regardless of the point's `-unit` option, so Mapiah's appended unit had no equivalent in Therion's own output.
  * Therion UIS `label`, `remark`, `date`, `altitude`, `height`, and `dimensions` point text now renders at the same reduced size as `passage-height`'s containers (`THLabelSize.tiny`), instead of Mapiah's normal-sized text, which looked oversized compared to Therion's own rendering.
  * Therion UIS `water-flow -subtype paleo` points now render with a solid, filled arrowhead, matching `p_waterflow_paleo_UIS` (which both `thfill`s and `thdraw`s its triangle), instead of Mapiah's hollow outline-only arrowhead.
  * Therion UIS `moonmilk` points now render with three wavy tops, the middle one taller than the two side ones, matching `p_moonmilk_UIS`'s direction-constrained curve; the middle bump previously dipped instead of rising, and once fixed to rise, was the same height as the side bumps instead of taller.
  * Therion UIS `paleo-material` points now render as a bone silhouette — a shaft with two same-sized pairs of round knuckles at each end — instead of the previous blob shape, which didn't read as a bone at all; `p_paleomaterial_UIS`'s raw node sequence pinches to a sharp point when hand-ported as a single Bezier chain, so the knuckles are built from overlapping circles instead.
  * Therion UIS `pillar`, `continuation`, `pillars`, `stalactites`, and `stalagmites` points (plus, defensively, `stalactite`, `stalagmite`, `wall-calcite`, `karren`, `flute`, and `soda-straw`) no longer paint stray filled triangles/slivers at their line corners; their macros only `thdraw`, never `thfill`, but the shared fill/stroke draw dispatch also calls each symbol's draw method with a fill-style `Paint`, and Skia implicitly closes open subpaths when filling, turning V-shaped and zigzag strokes into unwanted solid wedges. Each now skips its own draw method on the fill pass. Added dispatch and golden regression coverage.
  * Therion UIS `water-flow -subtype permanent` and `-subtype intermittent` points now render with a solid, filled arrowhead, matching `p_waterflow_permanent_UIS`/`p_waterflow_intermittent_UIS` (fixed alongside `-subtype paleo` in the previous entry, but until now missed for these two subtypes since they never received a fill color at all).
  * Therion UIS `air-draught` points (and their `winter`/`summer` subtypes) now render their wing curves hugging the stem through most of their rise and flaring out to their base only near the bottom, matching `p_airdraught_UIS`'s `{dir 20}..{dir 90}` curve, instead of a smooth semicircular bulge curving the opposite way.
  * Therion UIS area fill patterns (`water`, `sump`, `debris`, `flowstone`, `moonmilk`, `sand`) no longer look blocky at most zoom levels; their pre-rendered pattern tile is bilinear-filtered (`FilterQuality.medium`) when scaled to match the current zoom instead of defaulting to nearest-neighbor sampling.
  * Therion UIS `crystal`, `stalagmites`, `stalactites`, `pillars`, `scallop`, `stalactite`, `stalagmite`, `wall-calcite`, `water-flow` (and its `-subtype intermittent`), `moonmilk`, `pillar`, `flute`, `guano`, `anastomosis`, `archeo-material`, `camp`, `continuation`, and `disk` points now use one pen tier thicker than their literal Therion pen (`PenC`→`PenB` for all of them except `camp`'s stroke, which was on `PenD` and moved to `PenC`); at typical zoom, their thin diagonal strokes didn't give antialiasing enough coverage width to smooth the edge, so they read as jaggy despite being antialiased. A deliberate, visible departure from Therion's literal pen weight, made after comparing render samples at increasing widths.
  * Therion UIS `water-flow -subtype intermittent` points' dashed body line is now actually visible as dashes instead of reading as a solid line indistinguishable from `-subtype permanent`; the dash segments' round stroke caps (inherited from the shared paint) extended further than the gap between them, fully bridging it, so the line always looked continuous regardless of the dash/gap lengths chosen. The dashed segments now use a butt cap instead.
  * Therion UIS `sand` points now render as three small dots arranged in a triangle, matching `p_sand_UIS` (which `thdraw`s three zero-length paths with a round pen, producing dots, not lines), instead of Mapiah's three radial line segments radiating from the center.
  * Therion UIS `guano` points now render with MetaPost-faithful control points, giving the hanging-drape symbol its V profile with a pointed bottom and two outward-humped arms, matching `p_guano_UIS`'s `{dir 40}..{down}(0,-.35u){up}..{dir-40}` path; the previous approximation curved the bottom into a rounded U. Updated the Phase 2 golden coverage.
  * Therion UIS `disc-stalagmites` points now render as three `0.7`-scaled stalagmite sub-symbols each with a short horizontal disc bar, matching `p_discstalagmites_UIS` (the `stalagmites` repeated-instance loop plus `(-.15u,.1u) -- (.15u,.1u)` per instance), instead of Mapiah's placeholder diamond. Updated the Phase 3 golden coverage.

## 0.4.3 - 2026-07-29 - The [Therion Symbology](https://marcocorvi.altervista.org/caving/tbe/m_02/m_025.htm) release
* Highlights:
  * Added the Therion UIS visualization method, with scalable vector point symbols, text labels, line decorations, and area patterns that can be compared directly with Mapiah's placeholder representation.
    * Reviewed and corrected to match Therion: gradient, survey (cave), pit/pitch, floor-step, chimney, ceiling-step, contour, and moonmilk lines; and water, debris, flowstone, moonmilk, and sand areas.
    * Implemented but not yet individually revised against the Therion showcase: air-draught (including winter/summer), anastomosis, archeo-material, blocks, camp, continuation, crystal, curtain, disk, dig, entrance, flowstone, flute, gradient, guano, helictite, ice, karren, low-end, moonmilk, narrow-end, paleo-material, pebbles, pillar/pillars, popcorn, sand, scallop, soda-straw, stalactite/stalactites, stalagmite/stalagmites, wall-calcite, water, and water-flow point symbols; altitude, date, dimensions, height, label, passage-height, and remark text points; ceiling-meander, flowstone, rock-border, rock-edge, wall:bedrock, wall:underlying, wall:presumed, and water-flow lines; and the sump area.
    * Not yet ported and still using placeholders: the UIS debris, curtains, disc-pillar/disc-pillars, disc-stalactite/disc-stalactites, disc-stalagmite/disc-stalagmites, helictites, pillar-with-curtains, pillars-with-curtains, stalactite-stalagmite, and stalactites-stalagmites point symbols, plus the default blocks area pattern.
  * Added freehand line drawing with live previews, endpoint snapping, configurable line types, undo/redo, and bounded Douglas-Peucker simplification.
  * Added optional snapping to points and line points in visible inactive scraps.
  * Improved desktop and file-opening reliability by restoring window placement, handling non-fatal parsing errors as warnings, and safely discarding failed or overlapping file loads.
* New features:
  * Mapiah now remembers its window size, position, and maximized state when closed on Linux, macOS, and Windows, and restores that placement the next time it opens. New installations default to maximized, and saved placements that are incompatible with the current display layout fall back to maximized.
  * Added a freehand line drawing tool: press and drag (mouse, touch, or stylus) to draw, see the raw stroke previewed live via `MPAddFreehandLineWidget`, and release to commit one editable `THLine` made of straight segments in a single undoable action, with SexyTopo-style bounded/compacted sample capture and extent-relative Douglas-Peucker simplification. Endpoint snapping, the current line type/subtype, applicable default options, and the active scrap are all respected, and the result round-trips through `.th2` save/reload. Discoverable via the add-element toolbar row and the `F` shortcut, with updated EN/PT help pages and keyboard-shortcut tables. [requested by Edvard]
  * Added independent "Snap to inactive scraps" options for point and line-point targets, allowing edits in the active scrap to snap to matching targets in visible inactive scraps while excluding hidden scraps. Snap targets now refresh when the active scrap or scrap visibility changes, with EN/PT help updates and regression coverage. [requested by CaverBruce]
  * Added a "Symbol unit" setting controlling the base pixel size (`u`) of Therion symbol-set renderings, defaulting to the previous fixed value; only affects the canvas when a Therion visualization method is selected. Added EN/PT settings labels, help documentation, and regression coverage.
  * Therion-faithful text points now show an orange circle at their exact anchor position, drawn above the label with twice the radius of persistent black line-point markers; added sizing and pixel-rendering regression coverage.
  * Added support for Therion's `pillars` point type (distinct from the existing singular `pillar`), previously unrecognized by Mapiah; it round-trips through `.th2` files and now also renders as a faithful Therion UIS symbol (see Phase 3 below). Added EN/PT labels and regression coverage.
* Fixed bugs:
  * TH2 files that only trigger caught, non-fatal parsing errors (e.g. a malformed `-author` date) now still open, showing the fully parsed drawing alongside a one-time, non-blocking "Parsing warnings" dialog listing what was skipped, instead of refusing to open the file entirely; only genuinely thrown, uncaught parse failures still block the file and discard load state. Added EN/PT localization and regression coverage.
  * Parser and other internal errors that are already caught and handled gracefully (e.g. a malformed `-author` date, shown via the regular "Parsing errors" dialog) no longer also pop a spurious "Unhandled error" dialog and abort loading the file; `THBaseException` no longer self-reports at construction time, and the app's global error handlers now report any exception, including `THBaseException` subtypes, only when it truly goes uncaught.
  * `-author`/`-copyright` scrap date values with a malformed range such as `2023.12-17` (likely a `2023.12.17` typo) no longer produce a cryptic grammar-level parse failure that also swallows the following line; the malformed range is now fully consumed by the date grammar and rejected with a clear, specific error message, matching how other invalid-but-shaped dates were already handled. Added grammar and end-to-end regression coverage.
  * Reopening a corrected TH2 file while the previous empty tabs page is still closing no longer creates overlapping editor routes that build the same controller-owned `GlobalKey`; tabs-page navigation now waits for the outgoing route to be fully removed before opening its replacement, with regression coverage for the pop/reopen transition.
  * Failed TH2 loads now immediately discard their cached load future, controller, and partially parsed object graph, including when parsing throws after registering elements; reopening a corrected file therefore reads its current contents instead of reusing failed state. Each file controller now also shares one single-flight parse among concurrent load requests, preventing the same fresh model from being parsed twice and triggering duplicate-THID exceptions such as the reported `119-PutaPlan-s2` failure. Added regression coverage for reported parse failures, thrown parser exceptions, and duplicate load requests.
  * Therion-faithful representations no longer retain or draw Mapiah's placeholder representation when a Therion visualization method is selected; visualization-method changes now repaint every element layer, and faithful representations respect the "Show line points" setting. Added regression coverage.
  * The visualization-method setting no longer offers the unimplemented Therion ASF, AUT, BCRA, NSS, NZSS, SBE, SKBB, and SM symbol sets; only Mapiah placeholders and the implemented Therion UIS set remain selectable.
  * Therion-faithful flowstone area patterns now use denser horizontal and vertical spacing with visibly staggered rows of narrow, slightly taller curves like Therion; boundary-crossing curves wrap into the raster tile instead of being clipped away, and the curves use Therion's original vertical orientation and ±60-degree endpoint directions instead of an inverted, overly broad quadratic approximation. Updated the Phase 1 area-pattern golden coverage.
  * Therion-faithful water area hatching now slopes in the correct direction after accounting for Mapiah's reflected Y axis; updated the Phase 1 area-pattern golden coverage.
  * Therion UIS water area hatching now has more space between its diagonal lines, increasing the hatch cell from `0.18u` to `0.4u`; centralized the area-pattern raster scale and water-spacing constants and updated regression coverage.
  * Therion UIS debris areas now render six irregularly distributed ticks per pattern tile instead of three, producing a denser representation; centralized the tick geometry and updated regression coverage.
  * Therion UIS moonmilk areas now match Therion's MetaPost pattern, using tightly packed rows of three same-direction cubic scallops, staggered by half a cell and oriented correctly on Mapiah's reflected canvas; boundary-crossing curves wrap seamlessly, geometry constants are centralized, and golden regression coverage was updated.
  * Therion UIS moonmilk lines now use MetaPost-faithful cubic control handles, increasing the wave amplitude from Mapiah's generic one-third segment length to approximately `0.568` and making the curls as visible as Therion's; added numeric and golden regression coverage without affecting flowstone lines.
  * Therion UIS contour lines now render as continuous, tick-free lines using the same color as Mapiah's contour placeholder instead of showing only a midpoint tick; added dedicated golden regression coverage.
  * Therion UIS survey lines now render their straight knot-to-knot paths as continuous `PenC` lines using the same color as Mapiah's survey placeholder; added dedicated golden regression coverage.
  * Therion UIS chimney and ceiling-step lines now render complete small-T symbols instead of isolated perpendicular ticks, using adjusted path-aligned caps and `0.2u` stems; the chimney orientation now accounts for Therion's reversed path, while both representations retain their existing separate colors. Added combined golden regression coverage.
  * Therion UIS pit and floor-step lines now include Therion's continuous `PenC` base line beneath their upper `PenD` ticks, retain their existing separate colors, and share an explicitly named decorator reflecting Therion's alias between the two symbols. Centralized their spacing constants and added combined golden regression coverage.
  * Therion UIS sand areas now use opaque black dots instead of Mapiah's faint placeholder color and reduce their grid spacing from `1u` to `0.7u`, making the pattern substantially more visible and roughly doubling its dot density; centralized the sand-pattern constants and updated golden regression coverage.
  * Applying, saving and closing, or resetting all values on the settings page now completely redraws every open TH2 drawing, so visualization-method and other rendering changes are applied consistently across all tabs; added multi-drawing widget regression coverage for all three actions.
  * Toggling direction ticks with `Ctrl/Cmd+Alt+R` now redraws every open TH2 drawing instead of only the active file, keeping the global setting consistent across tabs; added multi-drawing regression coverage.
  * Station points no longer display their station names as text labels when using the Therion UIS visualization method; UIS now retains placeholder rendering for station points, with regression coverage.
  * Therion-faithful orientable point symbols now remain upright and follow their configured orientation on Mapiah's reflected editor canvas instead of being mirrored; added pixel-level regression coverage for an oriented water-flow symbol.
  * The home-page and file-editor app bars now collapse their actions into overflow menus on narrow windows and avoid laying out toolbar controls during transient one-pixel Linux startup frames, preventing horizontal RenderFlex overflow errors; both bars share the same responsive implementation, Linux attaches the Flutter view before showing the native window, and regression coverage exercises the home page and a 380-pixel-wide editor.
