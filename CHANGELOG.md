# Changelog

## 1.0.1 - not yet released
* New features:
  * Added an "Add line segments" button to the line edit panel, matching the existing `/` shortcut that adds line segments between the selected line segments. The button is enabled when two or more end points are selected.
  * The scrap _Sketch_ option dialog can now fill the sketch filename and lower left corner coordinates from a raster image already loaded in the file, warning when that image is scaled or rotated since Therion doesn't support it (#44).
* Fixes:
  * Fixed the scrap _Sketch_ option dialog (#44): long filenames no longer push the dialog off screen, files picked with _Choose file_ are stored relative to the TH2 file, the filename field no longer loses its cursor while typing, and switching between _Unset_ and _Set_ now updates the OK button correctly.

## 1.0.0 - 2026-09-24 - The [Frankfurt School](https://en.wikipedia.org/wiki/Frankfurt_School) release
* Highlights:
  * Whole Therion projects can now be opened and worked on: a resizable project-tree sidebar shows the `thconfig`/`.th`/`.th2`/survey/scrap hierarchy with search, dirty and error markers, and a Close project action. The separate initial window was replaced by an always-available tabbed workspace, and running Therion uses the loaded project, with its compiler diagnostics shown in the tree and editors.
  * `thconfig` and `.th` files open in an integrated text editor tab, with find/replace and project-aware Save As that updates the references of the other project files.
  * The project tree lists each `.th2` file's scraps, points, lines and areas in drawing order, loading files in the background without opening tabs. Clicking an element selects it, double-clicking zooms to it, and drawing order can be changed by dragging rows, from a right-click menu, or with Ctrl/Cmd+[ and Ctrl/Cmd+]. Stations, labels and remarks show their names and texts, which search also matches.
  * Broken `.th2` files are handled much better: problems are reported once, at the right line, with a localized explanation and the offending source line; areas with unusual border ids are no longer deleted silently; and a fixed file can be reloaded from its tab.
  * Added the SKBB and AUT Therion symbol sets alongside UIS, with sets now falling back to Therion's own default symbols instead of UIS.
  * Added printable English and Portuguese user guides (PDF) attached to each release, and new `B` (slope border) and `V` (visibility) toggle shortcuts; the flip actions were renamed to mirror (`Alt+M`/`Ctrl+M`), and Merge areas moved to `Ctrl+Alt+M`.
  * Fixed several Windows problems: Save As breaking or lowercasing image paths, the Therion run dialog hanging after a fatal error, and the window staying frozen on screen while closing.

  * On Windows, Save As of an existing `.th2` file no longer breaks or lowercases its image paths.

    * Absolute image paths were rewritten in lowercase. They are now left exactly as written, and their lines keep their original formatting.

    The cause was `p.canonicalize`, which lowercases paths on Windows, combined with a case-sensitive POSIX relative-path calculation. Added Windows-path tests (`test/t0816`).

Mapiah now closes Therion's input as soon as it starts, so these pauses end at once and the dialog shows the red error status. Added regression coverage (`test/t3600`). [reported by CaverBruce]

Added widget coverage (`test/t3938`).

  * Broken `.th2` files (#32, Phase 1) are now reported more precisely:
    * A structural error no longer produces extra errors further down the file. A `point`, `line` or `area` outside any scrap, a scrap inside another scrap, and a missing `endline`/`endarea` are each reported once, at the right line. An unclosed scrap, line or area at the end of the file no longer adds a generic "multiline commands left open" error.
    * An unknown option on a `scrap`, `line` or `area` line is reported once at that line, and the rest of the block is read normally instead of being skipped. A misspelled command inside a scrap no longer hides the lines after it.
    * An unknown option line inside an area (for example `weirdareaopt 5` or `clip middle`) is reported instead of being dropped silently.

    * When Mapiah has to repair an invalid line id (for example `-id b@1` becomes `b_1`), border references that spell the same id are repaired the same way. Before, the two sides were repaired differently, the reference no longer matched, and the area was removed.
