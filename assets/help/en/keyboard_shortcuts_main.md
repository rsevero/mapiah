_Note: Mapiah treats the Ctrl and Meta (Command on macOS) keys as interchangeable. Shortcuts below show "Ctrl" for brevity._

| Function                                               | Shortcut               |
| ------------------------------------------------------ | ---------------------- |
| Create file                                            | Ctrl+N or Ctrl+Shift+N |
| Help                                                   | F1                     |
| Keyboard shortcuts                                     | Ctrl+K                 |
| Open project                                           | Ctrl+O or Ctrl+Shift+O |
| Open project and run Therion when no project is loaded | Ctrl+T                 |
| Run/rerun Therion for the current project              | T                      |

### Text editor

These shortcuts apply when a `thconfig` or `.th` text tab is active.

| Function                                 | Shortcut |
| ---------------------------------------- | -------- |
| Find and replace in the active text file | Ctrl+F   |
| Save the active text file                | Ctrl+S   |

`Ctrl/Cmd+T` is unavailable for switching projects once a project is loaded.
