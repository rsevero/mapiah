_Observação: no Mapiah as teclas Ctrl e Meta (Command no macOS) são intercambiáveis. Nos atalhos abaixo usa-se "Ctrl" por brevidade._

| Ação                                                       | Atalho                 |
| ---------------------------------------------------------- | ---------------------- |
| Abrir projeto                                              | Ctrl+O ou Ctrl+Shift+O |
| Abrir projeto e executar Therion quando não há projeto     | Ctrl+T                 |
| Ajuda                                                       | F1                     |
| Atalhos de teclado                                          | Ctrl+K                 |
| Criar arquivo                                               | Ctrl+N ou Ctrl+Shift+N |
| Executar novamente o Therion para o projeto atual           | T                      |

### Editor de texto

Estes atalhos se aplicam quando uma aba de texto `thconfig` ou `.th` está ativa.

| Ação                                             | Atalho |
| ------------------------------------------------ | ------ |
| Localizar e substituir no arquivo de texto ativo | Ctrl+F |
| Salvar o arquivo de texto ativo                  | Ctrl+S |

`Ctrl/Cmd+T` não fica disponível para trocar de projeto depois que um projeto é carregado.
